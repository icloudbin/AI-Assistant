Theme
This prompt is sent to the selected model (DeepSeek, Gemini, Claude, ChatGPT, or OpenRouter) as a system instruction and can customize how the assistant interprets requests and formats its responses.
History Management
Backup exports all locally saved conversations to a ZIP file. Restore imports conversations from a backup ZIP and merges them with existing history. Delete permanently removes all saved conversation history. Your API keys and custom prompt are not included in backups.
Settings Backup
Export writes all settings — including API keys and your custom prompt — to a plain-text JSON file. Import restores them in one click, for example after removing and reinstalling the extension. Keep the file somewhere safe: it contains your API keys in readable form.
